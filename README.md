# 웨이크 드라이브 (Wake Drive) — 프로토타입

🔗 **바로 체험하기: [https://dong3789.github.io/wake-drive/](https://dong3789.github.io/wake-drive/)**

졸음운전을 "알람"이 아니라 **예측 + 음성 개입 + 쉼터 안내**로 막는 차량용 안전 앱의 프로토타입입니다.

현대차·기아 차량용 앱 개발 공모전 (Pleos Playground, 일반 부문) 제출용 참고자료입니다.
기획서(공식 접수양식)의 7. 참고자료 항목에 이 저장소 링크가 포함됩니다.

## 핵심 흐름 (기획서와 동일)

1. **예측 — 졸음 위험 점수**: 연속 주행 시간, 시간대(심야·새벽), 단조로운 구간(장거리 직선·정체),
   속도 변화 패턴, 경고등 등 차량 상태를 합산해 위험 점수를 실시간 계산합니다.
2. **개입 — 음성 각성 체크**: 위험 단계에 들면 TTS 음성 퀴즈로 반응 속도와 정확도를 측정합니다.
   화면을 보지 않고 음성만으로 수행해 주의분산을 막습니다.
3. **행동 — 쉼터 자동 안내**: 반응이 늦거나 틀리면 NaviHelper로 가장 가까운 졸음쉼터·휴게소를
   경로에 바로 반영해 안내합니다. ("쉴 곳까지 3분"처럼 구체적으로 제시)

## 실행 방법

[웹에서 바로 열기](https://dong3789.github.io/wake-drive/) 또는 `index.html` 파일을 브라우저에서 열면 됩니다. 별도 빌드나 서버가 필요 없습니다.

처음 열면 화면이 어둡게 딤 처리되고 각 부분에 대한 설명 말풍선이 순서대로 떠요(6단계 투어: 프로토타입 안내 → 위험 점수 → 주행 조건 → 각성 체크 → 쉼터 안내 → Pleos API 대응표). 퀴즈·쉼터 카드는 투어 중에 미리보기로 잠깐 보여주고, 투어가 끝나면 원래대로 숨겨져요. 다시 보고 싶으면 상단의 "💡 처음 오셨나요? 설명 보기" 버튼을 누르세요.

1. 시간대·구간·속도를 정하고 **주행 시작**을 누릅니다.
2. 위험 점수가 올라가면 음성 퀴즈가 출제됩니다. **음성으로 답하기**(브라우저 음성 인식) 또는
   입력창에 직접 입력해 답하세요. 10초 안에 답하지 못하면 쉼터 안내로 넘어갑니다.
3. **주행 종료·요약**을 누르면 총 주행 시간, 각성 체크 횟수, 쉼터 안내 여부를 요약합니다.

권장 환경: Chrome (음성 인식·음성 합성 지원), 한국어 음성 설정.

## 프로토타입의 범위 — 솔직한 설명

이 프로토타입은 실제 Pleos SDK 연동 전 단계입니다.

- 차량 데이터(속도·주행 시간·경고등)는 **시뮬레이션 값**입니다.
- 졸음쉼터·휴게소 정보는 **예시 데이터**입니다.
- 음성 퀴즈는 브라우저의 Web Speech API(TTS/STT)로 구현했습니다.

실제 구현은 Pleos Connect 에뮬레이터에서 아래 API로 연동합니다.

| 프로토타입 요소 | 실제 구현 (Pleos Playground) |
|---|---|
| 위험 점수 입력값 | Vehicle SDK — 속도·주행 시간·경고등 등 차량 상태 |
| 쉼터 안내 | NaviHelper — 목적지·경로·졸음쉼터/휴게소 위치 |
| 가장 가까운 쉼터 계산 | FusedLocation — GPS·IMU·카메라 융합 정밀 위치 |
| 음성 퀴즈 출제 / 답변 인식 | TTS / STT SDK — 화면을 보지 않는 각성 체크 |

## 개발 계획 (기획서 5번 항목 요약)

- **1주차**: 에뮬레이터에서 장시간 주행 상태 시뮬레이션 → 위험 점수 계산 로직 구현 → TTS/STT 음성 퀴즈 프로토타입
- **2주차**: NaviHelper 기반 쉼터 안내 연동 → 시연 시나리오 완성(정상 주행 → 위험 단계 진입 → 음성 체크 실패 → 쉼터 안내) → 최종 PT 자료 준비

## 문제 정의 근거 (기획서 2번 항목)

- 경찰청 교통사고 통계(2019~2023년): 졸음운전 교통사고 10,765건, 사망 316명.
  사고 100건당 사망 2.9명으로, 같은 기간 음주운전(1.5명)의 약 2배. 고속도로에서는 100건당 8.3명 사망.
  (출처: 경찰청 보도자료 2024.4.5)
- 한국도로공사 10년 분석: 고속도로 교통사고 원인 중 졸음운전이 22.5%로 가장 큰 비중.
- 경찰청 자료(2022~2024년): 졸음운전 사고 5,521건(2022년 1,849건, 2023년 2,016건, 2024년 1,656건).

예상 MAU 같은 수치는 서류 단계에서 지어내지 않았습니다. 시연 단계에서 장거리 운전자 대상
설문·주행 데이터 기반으로 검증합니다.
